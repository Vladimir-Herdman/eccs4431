Initial bison and flex file setup from [Wikipedia](https://en.wikipedia.org/wiki/GNU_Bison).
Makefile's my personal setup from a previous project.

Their Setup:
- Copy `Expression.c`, `Expression.h`, `Lexer.l`, `Parser.y`, `main.c`.
- Run `flex Lexer.l` to generate lexical analyzer.
- Run `bison Parser.y` to generate parser.
